# SauceDemo Automation - Playwright + Cucumber

## Requisitos
- Node.js 18+
- npm

## Instalación
npm install
npx playwright install

## Ejecutar tests
npm test

## Patrón utilizado
Page Object Model (POM)

## Cobertura
- Login válido
- Login inválido (locked_out_user)
- Agregar producto
- Ver carrito
- Completar compra

## Usuarios
standard_user / secret_sauce
locked_out_user / secret_sauce
